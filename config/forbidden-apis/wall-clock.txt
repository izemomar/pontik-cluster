# --------------------------------------------------------------------------
# Wall Clock
# --------------------------------------------------------------------------
#
# Every call below reads this node's wall clock. The lease package never
# makes one: the database clock decides when a lease runs out, and every
# deadline this node keeps runs on System.nanoTime, so a clock that jumps
# can never move a lease. The build checks the compiled lease classes
# against this list, so a method reference or a static import is caught
# as surely as a plain call.
#

@defaultMessage The lease package reads time only from System.nanoTime or the database clock
