# Security Policy

**PLEASE DON'T DISCLOSE SECURITY-RELATED ISSUES PUBLICLY, [SEE BELOW](#reporting-a-vulnerability).**

## Supported Versions

Security fixes are released for the latest version of Pontik Cluster.

## Reporting a Vulnerability

If you discover a security vulnerability within Pontik Cluster, please use the
*Report a vulnerability* button under this repository's Security tab. If that is not
available to you, send an email to oss@izem.dev instead. All security vulnerabilities
will be promptly addressed.

To help us understand the problem, please include the version you are running, your
engine and database versions, what you observed, and how we can reproduce it. If you
are not sure whether what you found is a vulnerability, please report it anyway.

We will acknowledge your report within 7 days, and we will work with you to disclose
the issue within 90 days, or sooner if we both agree. We will also credit you in the
advisory, unless you would rather we didn't.

## Scope

This policy covers everything in this repository and everything the project
distributes. Vulnerabilities in the engine, the database, or a JDBC driver belong with
their own maintainers. However, if you found one through Pontik Cluster, please tell us
as well, and we will pass it along with your agreement.
